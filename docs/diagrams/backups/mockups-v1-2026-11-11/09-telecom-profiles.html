Mid level · Telecom recipe comparison

A shared baseline does not mean identical stacks

Each market selects approved local configuration while inheriting a versioned common service baseline. The same pattern is repeated for all sixteen stacks.

Conceptual recipe composition, independent of IaC. In this repository the adopter encodes the baseline in platform configuration and explicit module requests. There is no built-in telecom profile API, automatic profile-merging service or shipped telecom dashboard pack.

Evidence: Platform configuration; SSO profiles; module inputs.
