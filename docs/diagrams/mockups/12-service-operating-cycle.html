High level · Operating model with resource ownership

Service operating cycle

A market stack stays a managed service after its first creation. Each change, observation and review updates the service record; retirement leaves the operating cycle.

This is an adopter operating model, not a shipped service-catalog CRD, a single controller loop or a claim that every stage runs synchronously. The record can be assembled from Git, request status, provider observations and the adopter’s change system.

Sources: governance; credential lifecycle; retirement contract.
