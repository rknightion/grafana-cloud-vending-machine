A market stack, opened up

The foundation, stack-local resources and external dependencies occupy different scopes. This cutaway names the resources that a market can select instead of treating the stack as an empty destination.

This is an available-capability map, not a default object count or a physical deployment map. The managed-kind atlas disambiguates repeated names and lists all activated GVKs. Cloud acceptance is not established by rendering.
