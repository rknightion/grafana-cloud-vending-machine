High level · Tool independent

Grafana Cloud vending service

The platform owns a repeatable service definition. A request selects a market and its required capabilities; the delivery engine configures the stack and exposes an operating contract.

Terraform, Crossplane and direct API automation can implement the concept. Selection, dependencies, drift ownership, rotation and retirement must be designed explicitly; the delivery tool does not make them automatic.
