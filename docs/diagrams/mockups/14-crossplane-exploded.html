What Crossplane actually reconciles

Pull apart one request to see the ownership boundaries: Argo syncs declarations, the composition function assembles desired Kubernetes state, provider controllers reconcile Grafana, and ESO carries credentials through a separate secret bridge.

Logical responsibilities, not physical planes or a provisioning sequence. Crossplane invokes the function and applies its desired set. The Grafana provider makes external API calls. ESO separately reconciles ExternalSecret and PushSecret objects; the external store is not a Grafana resource. Namespaced ProviderConfigs can carry organization, instance or product credentials. Listed specialist kinds illustrate optional selections.

Exact implementation sources: request ApplicationSet; annotation resource tracking; namespaced XRD and pipeline Composition input; resource assembly, readiness and ESO objects; observed team ID gates; telemetry access-policy chain; activated managed kinds; example SecretStore and organization credentials. The AWS integration is an example, not a required deployment target.
